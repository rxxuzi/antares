Introduction

Welcome to the Antares User Guide. This document is designed to help you understand the features and functionality of Antares, a web-based file manager. Here you will learn how to navigate, manage files, and make the most of the tool.

Getting Started

To begin using Antares, simply launch the application and log in. The interface is designed to be intuitive:

  • Navigation: Browse your directories using the sidebar and top navigation.
  • File Operations: Upload, delete, move, copy, rename, and create new directories using the provided controls.
  • Search: Quickly locate files using advanced search options.

No complex setup is required—Antares is ready to use out of the box.

Features

Antares offers a comprehensive set of features:

  • File & Directory Management: Perform all basic file operations directly from the web interface.
  • Real-time Updates: Watch server health and file changes in real-time.
  • Advanced Search: Use Boolean operators, case sensitivity, and regex to quickly filter your files.
  • Responsive Design: Enjoy a consistent experience across desktop and mobile devices.

Usage Tips

Here are some best practices to get the most out of Antares:

  • Organize your files: Use descriptive folder names and subdirectories to keep your files organized.
  • Use the search function: Take advantage of advanced search operators (OR, AND, NOT) and regex for quick filtering.
  • Keyboard shortcuts: Familiarize yourself with available shortcuts to streamline your workflow.
  • Regular updates: Check the health status and logs regularly to ensure optimal performance.

Frequently Asked Questions

Q: How do I upload files?

A: Click the "Upload" button in the sidebar and select the file(s) from your computer. The file will be added to the current directory.

Q: What happens if a file with the same name already exists?

A: Antares will automatically rename the new file to avoid overwriting existing files.

Q: How do I perform an advanced search?

A: Use the search bar along with the options for case sensitivity and regular expressions. Refer to the Search Documentation for detailed instructions.

Q: Where can I find more information?

A: You can navigate to the API Documentation or Search Documentation for more in-depth details about each feature.
