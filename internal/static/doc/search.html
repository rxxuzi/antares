Introduction

Antares provides powerful search functionality for navigating through your files and directories. This guide will help you understand and make the most of the search features, from basic keyword searches to complex queries using Boolean logic and regular expressions.

Basic Search

To perform a basic search, simply type the keyword(s) into the search box. For example, typing document will return all files and folders containing the word "document".

Search Operators

Refine your search results using these operators:

  • OR Search: Use || or OR between terms.
    Example: jpg || png returns files containing either "jpg" or "png".
  • AND Search: Use && or AND between terms.
    Example: document && pdf returns files including both "document" and "pdf".
  • NOT Search: Use NOT or !! before a term to exclude it.
    Example: image NOT png excludes files containing "png".

Regular Expression Quick Guide

When you enable regular expression search, you can use special symbols for flexible queries:

  • . - Matches any single character
  • * - Matches zero or more of the preceding character
  • + - Matches one or more of the preceding character
  • ? - Matches zero or one of the preceding character
  • ^ - Matches the start of the string
  • $ - Matches the end of the string
  • [abc] - Matches any one character in the brackets
  • [^abc] - Matches any character not in the brackets

Examples:

\.pdf$ - Matches filenames ending with ".pdf"

^img_\d+\.jpg$ - Matches filenames like "img_123.jpg"

Advanced Search Examples

Combine multiple operators and regex patterns for sophisticated searches:

  • Combination Search: report && (2021 || 2022)
    Returns reports from either 2021 or 2022.
  • Exclusion Search: invoice NOT (draft || sample)
    Returns invoices while excluding those labeled as "draft" or "sample".
  • Regex for Date Formats: ^\d{4}-\d{2}-\d{2}$
    Matches filenames that exactly match a date format like "2023-07-25".

Frequently Asked Questions

Q: What if my search returns too many results?

A: Try refining your query by combining multiple operators or using more specific regex patterns.

Q: How do I search for filenames with special characters?

A: If your filename contains regex metacharacters (e.g. ., *), escape them using a backslash (\).

Q: My regex search isn't working as expected. What should I do?

A: Verify your regex syntax using an online regex tester such as regex101.com. Ensure that you have enabled the regex option in the search interface.
